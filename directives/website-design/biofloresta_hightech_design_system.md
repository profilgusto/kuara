# 🌿 Biofloresta High-Tech --- Diretrizes Visuais e Estéticas

## 1. Identidade Conceitual

O website deve transmitir:

-   🌿 Ecossistema dinâmico
-   🔬 Ciência estruturada
-   🎓 Ensino acadêmico
-   🧪 Centro de pesquisa aplicada
-   🛰️ Tecnologia ambiental high-tech

Sensação geral: \> Laboratório vivo dentro de uma universidade moderna.

------------------------------------------------------------------------

# 2. Sistema de Cores

## 🌑 DARK MODE (Principal)

### Background Layers

-   Background Base: #0B1411 (solo profundo)
-   Surface 1: #11201A (musgo úmido)
-   Surface 2: #162A22 (folhagem noturna)
-   Border: #1F3A30 (tronco discreto)

Preto nunca deve ser puro (#000000). Sempre levemente esverdeado.

------------------------------------------------------------------------

-   Primary: #3FAF5C
-   Primary Hover: #2F8C49
-   Primary Glow: rgba(63,175,92,0.25)

-   Accent: #5B7F6E

------------------------------------------------------------------------

-   Sand: #C9BFA3
-   Clay: #A56E4A

-   Background: #F2F5F1

consistente.

# 3. Tipografia

-   IBM Plex Sans 400

------------------------------------------------------------------------

# 4. Princípios de Layout

-   Muito espaço negativo
-   Estrutura modular
-   Hierarquia clara
-   Sem excesso de elementos visuais
-   Nada visualmente comprimido

O site deve parecer organizado, respirável e didático.

------------------------------------------------------------------------

# 5. Microinterações

## Movimento Base

-   Duração média: 220--320ms
-   Easing suave (ease-in-out)
-   Nada abrupto
-   Sem bounce ou elastic exagerado

------------------------------------------------------------------------

## 🌱 Botões

Estado normal: - Fundo transparente - Borda verde - Texto verde

Hover: - Fundo preenche suavemente - Glow verde sutil - Transição
\~240ms

Active: - Leve compressão (scale 0.98)

------------------------------------------------------------------------

## 🌊 Links

-   Cor Secondary
-   Underline animado da esquerda para direita
-   250ms
-   Aparência de fluxo de energia

------------------------------------------------------------------------

## 🌿 Scroll Reveal

-   Leve deslocamento vertical (6--8px)
-   Fade in
-   300ms

Sensação: crescimento controlado.

------------------------------------------------------------------------

## 📊 Dados e Gráficos

-   Animação de contagem progressiva
-   Linhas desenhando suavemente
-   Nunca instantâneo

Sensação: monitoramento ambiental em tempo real.

------------------------------------------------------------------------

## 🌌 Fundo Vivo (Opcional)

-   Gradiente extremamente sutil
-   Variação lenta (25--40 segundos por ciclo)
-   Deve ser sentido, não percebido conscientemente

------------------------------------------------------------------------

# 6. Atmosfera Final

Dark Mode: \> Floresta noturna com sensores captando dados.

Light Mode: \> Centro de pesquisa ecológico contemporâneo.

Este sistema visual deve transmitir rigor científico, vida orgânica e
inovação aplicada de forma equilibrada e elegante.
